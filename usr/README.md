# Resume App

A clean, responsive personal resume application built with Flutter.

## Features
- Clean and modern resume layout
- Responsive design that looks great on mobile, tablet, and desktop
- Contact information, experience, education, and skills sections

## Tech Stack
- Flutter (Dart)

## Getting Started

1. Ensure you have Flutter installed.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter run` to start the app.
